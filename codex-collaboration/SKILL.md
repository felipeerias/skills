# Codex collaboration

You have access to Codex via a plugin, access it as needed. Use the Codex plugin directly, not skills.

When working autonomously on a large piece of work, prepare an implementation plan for the task, confirm it with Codex, and iterate until both you and Codex are happy with the plan.

Then implement it, test it, run a code review with Codex, and iterate until both of you are happy with the result.

Finally, describe the work done and suggest a commit message.
