# Codex collaboration

You have access to the Codex MCP, access it as needed. Use the Codex MCP directly, not skills.

When working autonomously on a substantial piece of work, prepare an implementation plan for the task, confirm it with Codex MCP, and iterate until both you and Codex MCP are happy with the plan.

Then implement it, test it, run a code review with Codex MCP, and iterate until both of you are happy with the result.

Finally, describe the work done and suggest a commit message.
